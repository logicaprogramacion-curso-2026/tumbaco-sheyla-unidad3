# MiniTienda - Sistema de Registro y Análisis de Ventas

## Descripción
Sistema de consola para gestión de ventas con análisis de datos.

## Requisitos Cumplidos
- ✅ Catálogo con tuplas
- ✅ Precios/Stock con diccionarios
- ✅ Registro de ventas con listas
- ✅ Guardado/Carga en CSV
- ✅ Análisis con Pandas/NumPy
- ✅ Gráficos con Matplotlib
- ✅ Menú interactivo

## Estructura del Proyecto
- `MiniTienda.py`: Código principal
- `ventas.csv`: Datos de ventas
- `log.txt`: Registro de errores
- `ingresos.png`: Gráfico exportado
